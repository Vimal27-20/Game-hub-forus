# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [2.1.0] - 2026-10-12 · Word Grid and Netflix-style menu (spec 004)

### Added
- 🔠 **Word Grid**: a Boggle-Party-style word hunt. A shared 4×4 or 5×5 letter grid, with players tracing words on their phones (drag or tap). It has a unique-word bonus, a live "found a 6-letter word!" feed, and a round reveal of the longest and missed words.
- A 78,776-word dictionary (SCOWL ≤ 60, profanity removed), generated by `npm run dict`. Notice in THIRD_PARTY_NOTICES.md.
- Gzip compression for everything the server sends.

### Fixed
- TV menu: games that didn't fit the screen (the end of the Action row) can now be reached. Netflix-style browsing scrolls the focused row up under the billboard and scrolls each row sideways. Mouse-wheel, touch and ‹ › arrows work for pointer remotes.

## [2.0.0] - 2026-10-12 · Party Pack v2 (spec 003)

### Added
- Six new games: ⛳ Mini Golf Mayhem, 🐍 Light Trails, 🌋 Lava Rise, 🤠 Quick Draw, 🎭 Fake Out and 📏 Close Call.
- TV main menu with Games / Settings / How to play tabs, games grouped by category, and a setup sheet for each game's settings.
- Back on the TV pauses (Resume, Restart, Sound, Vibration, Quit), and Back again quits. A browser-history trap means Back never leaves the site.
- The 👑 phone can pause, resume, restart, quit, skip scoreboards, change settings and pick the next game.
- Rejoin mid-game: a returning phone goes straight back into the running game with its score. Seats are kept for 15 minutes.
- Short join link `site/ABCD`, and a `/` chooser with a Rejoin button.
- Live score strip, round scoreboards, awards, instant results with Play again / Next game / Menu, and tonight's standings that survive a TV reload.
- Room settings (length, difficulty, sound, volume, vibration) and per-game settings, remembered on the TV.
- Content banks: 182 quiz questions (true/false and closest-number styles), 66 number questions, 206 drawing words in 3 levels, 16 Undercover categories and 62 Fake Out facts. Nothing repeats within a night.
- A game runner with fixed 120 Hz physics, game-time timers and smoothed input. Each round picks a different arena, mode or rule.
- Tests: runner, content and bot playthroughs of all 11 games, plus `npm run smoke` (headless Chrome, TV and phone).

### Changed
- All five original games were rebuilt on the runner, with settings, round variants, awards and rejoin support.
- The Lobby button on the phone is now Pause.

## [1.1.0] - 2026-10-12 · Repository standards and TV store apps (spec 002)

### Added
- TV store apps from one codebase: LG webOS, Samsung Tizen, and Android TV / Fire TV through Capacitor (spec 002).
- `public/platform.js` adapter: remote Back/OK keys on every TV and platform-native app exit.
- `scripts/build-tv.mjs`, which builds store bundles against a hosted hub (`HUDDLE_SERVER_URL`).
- Store icons and banners generated from SVG (`npm run icons`).
- `/healthz` endpoint, `ALLOWED_ORIGINS` CORS setting, graceful shutdown, a Dockerfile and a Render blueprint.
- Contract tests for the socket protocol and the TV builds, plus ESLint, CI, a release workflow and Dependabot.
- A spec-driven workflow (`specs/`), with baseline spec 001 for the core platform, and `CLAUDE.md`.

### Changed
- The server moved to `server/` (`createApp()` factory + `server/index.js`). Start it with `npm start` as before.
- TV page assets use relative paths so the page works when packaged.
- The minimum Node version is now 22.

### Fixed
- `player:char` now rejects empty ids and requests from non-player sockets.
- Kicking a player clears their reconnect timer, and closing a room clears every player timer.

## [1.0.0] - 2026-10-12

### Added
- First version: TV-hosted lobby, QR join, five games (Bumper Brawl, Undercover, Quiz Clash, Doodle Dash, Tug Rally), character select, session trophies, and rejoin after a disconnect.
